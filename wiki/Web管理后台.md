# Web 管理后台

启动后访问 `http://<主机IP>:8008`，默认账号 `admin` / `admin123`（请务必修改为强口令）。

---

## 仪表盘
- 账号数、已登录数、任务数、运行中任务、累计查询次数
- 系统运行状态：Web / 集群 / CDN / 日志

## 账号管理（核心）
- **添加账号**：支持扫码登录（推荐）与密码登录
- **扫码登录**：点击「扫码登录」显示二维码，用 12306 App 扫描即可完成登录，无需在配置文件中填写密码
- **多账号切换**：可添加多个账号，不同抢票任务可指定不同账号
- **乘客列表**：查看已登录账号的常用联系人
- **删除账号**：移除账号；所有变更自动保存，容器重启后自动恢复

## 抢票任务管理
- **新建任务**：选择账号、出发日期、出发/到达站（支持搜索自动补全）、乘客、座位类型、指定车次、时间范围
- **任务列表**：查看状态（运行中 / 待启动）
- **删除任务**：移除任务；任务创建后立即运行，自动查询并在有票时提交订单

## 实时日志
- 实时查看运行日志，支持自动滚动、手动刷新

## 动态配置持久化
Web 后台添加的账号与任务保存在 `/data/config.json`（Docker 数据卷），容器重启后自动加载，无需修改 `env.py`。
