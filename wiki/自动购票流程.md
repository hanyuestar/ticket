# 自动购票流程

本分支已贯通「查询 → 打码 → 提交订单 → 确认支付」的完整自动购票链路。

---

## 前置条件
1. 已在 `env.py` 的 `USER_ACCOUNTS` 配置 12306 账号并完成登录（推荐 Web 后台扫码登录）。
2. 已创建至少一个 `QUERY_JOBS` 查询任务，且 `account_key` 指向已登录账号。
3. 打码平台可用（`AUTO_CODE_PLATFORM='free'` 默认即可；或配置若快/自定义 OCR）。

> 若仅配置 `QUERY_JOBS` 而未配置 `USER_ACCOUNTS`，程序只查询余票、不自动下单。

## 流程步骤
1. **查询余票**：系统按 `QUERY_INTERVAL` 循环查询 `left_dates` / `stations` / `seats` 等条件。
2. **站点一致性校验**：本版本对返回的 `from/to` 站点码与查询站码做比对，避免买到同名错站车票（如广州北→衡阳东）。
3. **验证码打码**：命中余票时调用打码平台识别验证码。
4. **提交订单**：通过 12306 下单接口提交，校验乘客、座位、车次。
5. **确认支付**：下单成功后等待用户在 12306 App 内完成支付（程序不代付）。
6. **多账号并发**：不同任务可使用不同账号同时运行。

## 关键修复点（本分支）
- 扫码登录流程重写（`user/job.py`），修复登录失效。
- 车次信息解析适配（`query/query.py` / `query/job.py`）。
- 起始/到达站一致性校验（`query/job.py`），防止下错站。

## 排错
- 能查到票但不下单 → 检查账号是否已登录、`account_key` 是否对应。
- 验证码环节失败 → 检查打码平台配置与网络。
- 下错站 → 本版本已修复；如仍出现请附日志提交 Issue。
