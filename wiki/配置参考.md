# 配置参考（`env.py`）

所有运行参数集中在根目录 `env.py`。以下为常用配置项说明。

---

## 账号与任务

### USER_ACCOUNTS
12306 账号列表。留空则程序**仅查询余票、不自动下单**。
```python
USER_ACCOUNTS = [
    {
        'key': 0,                    # 任务中通过 account_key 引用
        'user_name': 'your_user_name',
        'password': 'your_password',
        'type': 'qr'                 # 'qr' 扫码登录；其他值=密码登录
    },
]
```

### QUERY_JOBS
查询/抢票任务列表。
```python
QUERY_JOBS = [
    {
        'account_key': 0,            # 对应 USER_ACCOUNTS 的 key
        'left_dates': ['2026-10-01'],
        'stations': {'left': '北京', 'arrive': '深圳'},
        'members': ['张三'],
        'allow_less_member': 0,      # 是否允许乘客数不足也下单
        'seats': ['硬卧', '硬座'],
        'train_numbers': [],         # 指定车次（空=不限）
        'except_train_numbers': [],  # 排除车次
        'period': {'from': '00:00', 'to': '24:00'}
    },
]
```

---

## 查询与网络

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `QUERY_INTERVAL` | `1` | 查询间隔（秒），实际取 间隔/2 ~ 间隔 间随机值 |
| `REQUEST_MAX_RETRY` | `5` | 网络请求重试次数 |
| `USER_HEARTBEAT_INTERVAL` | `120` | 用户心跳检测间隔（秒） |
| `QUERY_JOB_THREAD_ENABLED` | `0` | 多线程查询（0=关闭，1=开启）|

---

## 打码平台

| 配置项 | 说明 |
|--------|------|
| `AUTO_CODE_PLATFORM` | `free`=免费接口；`ruokuai`=若快；`user`=自定义 |
| `AUTO_CODE_ACCOUNT` | 若快账号 `{'user','pwd'}` |
| `API_USER_CODE_QCR_API` | 自定义 OCR 服务地址（指向自有打码服务）|

---

## 通知方式

| 配置项 | 说明 |
|--------|------|
| `NOTIFICATION_BY_VOICE_CODE` | 语音验证码通知（需阿里云 API 市场 APPCODE）|
| `DINGTALK_ENABLED` / `DINGTALK_WEBHOOK` | 钉钉 |
| `TELEGRAM_ENABLED` / `TELEGRAM_BOT_API_URL` | Telegram |
| `SERVERCHAN_ENABLED` / `SERVERCHAN_KEY` | ServerChan 微信推送 |
| `PUSHBEAR_ENABLED` / `PUSHBEAR_KEY` | PushBear 微信推送 |
| `BARK_ENABLED` / `BARK_PUSH_URL` | Bark iOS 推送 |
| `EMAIL_ENABLED` 及 `EMAIL_*` | 邮件通知 |

## 分布式集群（可选）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `CLUSTER_ENABLED` | `0` | 是否启用集群（需 Redis）|
| `NODE_IS_MASTER` | `1` | 是否主节点 |
| `NODE_SLAVE_CAN_BE_MASTER` | `1` | 从节点可否晋升主节点 |
| `NODE_NAME` | `'master'` | 节点名称 |
| `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD` | `localhost/6379/''` | Redis 连接 |

---

## 运行数据与日志

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `OUT_PUT_LOG_TO_FILE_ENABLED` | `1` | 是否输出日志到文件 |
| `OUT_PUT_LOG_TO_FILE_PATH` | `/data/12306.log` | 日志路径 |
| `RUNTIME_DIR` | `/data/` | 运行时根目录 |
| `QUERY_DATA_DIR` | `/data/query/` | 查询缓存目录 |
| `USER_DATA_DIR` | `/data/user/` | 用户数据目录 |
| `CDN_ENABLED` | `0` | CDN 查询加速 |
| `CACHE_RAIL_ID_ENABLED` | `0` | 浏览器缓存 RAIL ID |

> Docker 部署时上述路径已映射到数据卷，修改 `env.py` 后 `docker-compose restart` 生效。
