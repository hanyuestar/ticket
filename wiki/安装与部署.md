# 安装与部署

本分支支持两种运行方式：**Docker 部署（推荐）** 与 **本地运行**。

---

## 一、Docker 部署（推荐）

### 前置要求
- 已安装 Docker 与 Docker Compose
- 无需数据库、无需 Redis（单机模式默认关闭集群）

### 步骤

```bash
# 1. 进入项目目录
cd yiken123-py12306

# 2. （可选）修改配置
# 默认已启用 Web 管理；如需预置账号/任务，编辑 env.py

# 3. 构建并后台启动
docker-compose up -d --build

# 4. 查看日志
docker-compose logs -f
```

启动后访问 **http://localhost:8008** 打开 Web 管理页面。

### 数据持久化
- 配置文件：`./env.py` → 容器 `/config/env.py`（只读）
- 运行数据：命名卷 `py12306_data` → 容器 `/data`
  - 动态配置 `/data/config.json`
  - 日志 `/data/12306.log`
  - 乘客 `/data/user/*_passengers.json`
  - Cookie `/data/user/*.cookie`
  - 二维码 `/data/user/qrcode/*.png`
  - 查询缓存 `/data/query/`

### 常用命令
```bash
docker-compose up -d        # 启动
docker-compose down         # 停止
docker-compose restart      # 重启（改配置后生效）
docker-compose logs -f      # 实时日志
docker-compose ps           # 查看状态
```

> 镜像基于 `python:3.11-slim`，已预下载 `pyppeteer` 所需的 Chromium，首次运行无需联网下载浏览器。

---

## 二、本地运行

支持 **Python 3.11 及以上**（本分支已在 Python 3.14 下验证）。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置（项目已自带 env.py，直接修改即可）
# 3. 启动前测试
python main.py -t
# 4. 运行
python main.py
```

### 命令行参数
- `-t` 测试配置信息
- `-t -n` 测试配置信息与通知消息
- `-c <path>` 指定自定义配置文件

---

## 三、从源码验证（开发者）

```bash
# 语法编译校验（全量）
python -m py_compile $(find py12306 -name "*.py")
# 启动测试模式校验配置与账号
python main.py -t
```

滑块验证依赖 `pyppeteer` 内置 Chromium；本地首次运行会自动下载（请保证网络连通，或直接使用 Docker 镜像）。
